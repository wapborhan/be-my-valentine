# Be My Valentine (ভালোবাসার কথা)

A Valentine's proposal web app built with React, TypeScript, and Vite.

## Features
- **Proposal Link Generator**: Enter a beloved person's name (e.g. `Anika` or `Borhan + Anika`) to generate a shareable proposal link.
- **Recipient Experience**: Shows romantic quotes on interactive heart-button click with smooth animations.
- **Bangla Font Support**: Integrated with custom Bengali fonts (`SolaimanLipi`, `Li Kongka Borno Unicode`, `Li Sirajee Sheikh Unicode`).
- **Responsive Design**: Mobile-friendly layout and interactive UI.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
