# Be My Valentine (ভালোবাসার কথা)

A Valentine's proposal web app built with React, TypeScript, and Vite.

## Features
- **Proposal Link Generator**: Enter a beloved person's name (e.g. `Anika` or `Anis + Anika`) to generate a shareable proposal link.
- **Recipient Experience**: Shows romantic quotes on interactive heart-button click with smooth animations.
- **Bangla Font Support**: Integrated with custom Bengali fonts (`SolaimanLipi`, `Li Kongka Borno Unicode`, `Li Sirajee Sheikh Unicode`).
- **Responsive Design**: Mobile-friendly layout and interactive UI.

## Getting Started

### Install Dependencies
```bash
yarn
```

### Run Development Server
```bash
yarn dev
```

### Build for Production
```bash
yarn build
```

## GitHub Pages Deployment

This project includes automated deployment to GitHub Pages via GitHub Actions.

### Setup Instructions:
1. Go to your repository on GitHub.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
4. Push your changes to the `main` branch. The action will automatically build and publish the website.
5. Your app will be live at `https://<username>.github.io/be-my-valentine/`.
